# 工作库体检

库位置：`D:\工程项目\工作库`。先读 `CLAUDE.md`。

## 检查项

1. **目录不一致**：有页面没登记到 `index.md`，或 `index.md` 里的链接指向不存在的页面。
2. **断链**：`[[页面名]]` 找不到对应文件。
3. **孤立页面**：没有任何页面链接到它（`index.md` 除外）。
4. **过期待办**：`- [ ]` 且页面更新日期已久，或事项里的日期已过。
5. **矛盾**：同一事实（日期、数字、状态）在不同页面写法不同。
6. **缺失**：反复出现却没有独立页的人物、客户、概念。
7. **敏感内容**：出现密码、密钥。
8. **原始路径失效**：页面记的文件路径已不存在（用命令检查）。

## 步骤

1. 用 Glob/Grep 扫描全库，逐项检查，不要靠猜。
2. 输出报告：按严重程度列出问题，每条写明页面和具体位置。
3. 报告里把"可直接修"和"需要用户决定"的分开。
4. **默认只报告，不修改**。用户说"修"之后，才改可直接修的项，并在 `log.md` 顶部追加一条 `## YYYY-MM-DD 体检`。

## 注意

- 不删除页面。疑似重复或无用的页面，只建议，由用户决定。
- 没发现问题的检查项也要列出"已检查，无问题"，别只报坏消息。
