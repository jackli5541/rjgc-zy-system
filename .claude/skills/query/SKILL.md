# 查询工作库

库位置：`D:\工程项目\工作库`。用户的问题在命令后面，没有就问他想查什么。

## 步骤

1. 先读 `CLAUDE.md` 和 `index.md`，从目录判断哪些页面相关。
2. 读相关页面（需要时顺着 `[[ ]]` 链接继续读），不要通读全库。
3. 回答：直接给结论，并注明出自哪几页（写页面名）。
4. 库里没有或信息不足时，明说"库里没有记录"，不要凭印象补。若页面里的信息可能过期（日期、状态），提醒用户。
5. 回答本身有长期价值（如综合了多页的结论）时，问用户是否回写进库，同意才写，并更新 `index.md` 和 `log.md`。

## 注意

- 查询只读，不改库，除非第 5 步用户同意。
- 页面里记的是路径时，需要原文件内容才去读原文件。
