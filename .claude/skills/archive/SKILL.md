# 归档到工作库

库位置：`D:\工程项目\工作库`。先读该目录下的 `CLAUDE.md` 和 `index.md`，按其中规则执行。

## 步骤

1. 确定本次会话属于哪个项目（项目/〈类别—公司简称〉、创丰、教学、个人；新客户项目就在 `项目/` 下按“类别—公司简称”新建文件夹，命名方法见 CLAUDE.md）。根据当前工作目录和会话内容判断，拿不准就问用户。
2. 从会话提炼，只保留有长期价值的内容：
   - 做了什么、定了什么（含原因）
   - 产出文件的完整路径
   - 关键事实：日期、对象、数字
   - 未完成的待办
3. 在对应项目文件夹里更新已有页面；没有合适页面才新建。涉及客户、人物、通用方法的，写到 `跨项目/` 并用 `[[ ]]` 互链。
4. 更新 `index.md`（新页加一行，旧页说明有变就改）。
5. 在 `log.md` 顶部追加一条：`## YYYY-MM-DD 项目名`，下面 2-4 行说明改了哪些页。
6. 回复用户：列出新建和修改的页面，以及你没把握、需要他确认的地方。

## 注意

- 不写密码、密钥；电话邮箱只在用户明确要求时写。
- 不删除已有内容，只更新；新旧矛盾时改页面并在 log 注明。
- 不把原始文件复制进库，只记路径。
