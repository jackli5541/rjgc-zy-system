# 学生档案与导出

教学班成员行的查看按钮打开学生档案抽屉。档案包含基本资料、已发布或已结束的个人作业、当前有效提交附件、收到的有效互评及成绩。姓名编辑、重置密码和移出班级集中在抽屉内；归档班级只允许查看和导出。

## 接口

以下接口均要求登录且为对应教学班的教师，不向学生开放：

- `GET /api/v1/classes/{cid}/members/{uid}/portfolio`：返回 `member`、`summary`、`assignments`。逐次作业包含提交状态、截止和提交时间、版本号、迟交状态、附件、最终成绩及收到的有效互评。
- `GET /api/v1/classes/{cid}/members/{uid}/portfolio.zip`：导出单人档案。
- `GET /api/v1/classes/{cid}/portfolio.zip`：导出当前在班学生的档案；不包含已移出的学生。

新等级成绩沿用现有教师评分优先、互评次之的计算；逾期未交的系统 E 明确标记。待评分作业在曲线中断开。

## ZIP 内容

单人 ZIP 根目录包含 `学生档案.xlsx`，其中有“基本信息”“作业记录”“收到的互评”三个工作表；当前有效提交附件放在 `序号_作业名称/` 目录中。未提交作业仍列在表格中，但不生成空目录。

班级 ZIP 按 `学号_姓名/` 分目录，并复用单人档案的相同生成逻辑；每个目录都包含同样的 XLSX 和当前提交附件。单人 ZIP 使用 `学号_姓名.zip` 命名。只导出个人作业当前有效提交，不包含小组作业、历史提交附件、教师评分草稿或已作废互评。表格中的评语统一转换为纯文本，不保留 HTML 标签。

导出使用请求独立临时文件，下载完毕后关闭；文件名经过安全处理，同目录附件重名时增加序号。发现缺失附件时返回 `404 FILE_MISSING`，不下载部分内容。导出成功写入 `STUDENT_PORTFOLIOS_EXPORTED` 审计事件。无数据库迁移或新增环境变量。
