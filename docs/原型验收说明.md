# 正式版 MVP 验收说明

## 初始状态

执行 `scripts/init-local.ps1` 和 `scripts/start-local.ps1` 后访问 <http://localhost:8080>。开发环境仅 SQL Server 2022（兼容级别 120）在 Docker 中运行，前后端在本机运行。使用固定教师账号 `teacher / 123456` 登录；系统应显示空教学班状态，不能出现示例学生、小组、作业或成绩。

## 主流程

1. 教师创建教学班，上传包含“学号、姓名”列的 CSV 或 XLSX；XLSX 的名单表可以不是当前激活工作表。先预览校验再确认导入，并验证成员搜索、单独新增、查看、修改姓名、重置密码和移出。
2. 新学生使用“学号 / 学号”登录。未入组时只能看到组队页面，其他业务导航不可见且 URL 无法绕过。
3. 一名学生创建小组，另一名学生申请加入；组长同意后，申请人自动解锁导航并进入教学班首页。
4. 教师发布个人作业，两名同组学生分别上传并正式提交，检查版本号、提交时间和撤回规则。
5. 作业截止后，教师分别创建组内或班级一对一互评；学生只能看到冻结分配的唯一作品，提交 0 至 100 总分和必填评语。
6. 被评价学生在公开范围内查看实名分数和评语；教师查看统计并可填写原因作废评价。
7. 教师保存或发布成绩，学生只能看到已发布给本人的成绩；通知和审计记录同步生成。

## 自动验证

`docker compose --profile test run --rm test-api pytest -q` 覆盖空库、名单创建账号、入组门禁、作业富文本清洗、文件授权、Office 下载、提交版本冻结、组内/班级循环分配、人数不足跳过、评价校验、成绩留痕和归档限制。自动测试使用独立的 SQL Server `coursework_test` 数据库和临时文件系统，不接触开发运行数据；按项目约定跳过 E2E。
