# 前端架构与实现说明

> 版本：V2.0  
> 更新日期：2026-09-15

## 技术结构

前端使用 Vue 3、Ant Design Vue、Vue Router、Pinia 和 Vite。路由负责页面地址和入组门禁，Pinia 保存当前会话、教学班和小组关系；业务列表、统计、通知与操作结果全部来自 `/api/v1`，不保存演示数据。

开发阶段由本机 Vite 在 `8080` 端口运行，并将 `/api`、`/health` 代理至本机 FastAPI `8000` 端口；PostgreSQL 由 Docker 提供。生产阶段构建为静态文件后由 FastAPI 同源托管。

## 导航与权限

- 师生端统一使用顶部导航，窄屏下功能入口横向滚动。
- 教师可进入工作台、教学班、小组与选题、作业、互评、成绩和审计。
- 未入组学生只显示“加入小组”；路由守卫禁止进入其他页面。
- 创建小组或申请获批后刷新上下文，自动跳转教学班首页并解锁导航。
- 首页不重复展示“我的小组”卡片，小组详情集中在小组页面。

## 页面状态

每个数据页面提供加载、空数据和接口错误状态。写操作成功后重新读取服务端数据；会话使用 HttpOnly Cookie，前端只在内存中保存 CSRF Token。

作业发布弹窗使用 Tiptap 编辑说明，教师可在同一流程中保存草稿、上传多个附件并确认发布。PDF、Markdown 和图片提供预览，DOCX/XLSX 明确显示“下载查看”。

互评只关联已截止个人作业。教师选择“组内一人评一人”或“班级一人评一人”，填写标准或上传标准附件；学生页面只呈现服务端冻结的唯一对象和提交版本，提交 0 至 100 总分及必填评语。
