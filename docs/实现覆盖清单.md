# PRD 实现覆盖清单

> 当前实现核对：2026-09-21
> 原 PRD 的一对一百分制互评、Office 转码及 1 GB 文件上限属于历史需求基线；本表以当前代码为准。

| 编号 | 功能 | 正式实现 |
|---|---|---|
| F-01 至 F-04 | 认证、教学班、名单与首页 | SQL Server 会话、建班、多工作表名单识别与预检确认、成员单独增删改查、学号账号和真实摘要 |
| F-05 至 F-10 | 小组管理 | 创建、申请、审批、邀请、容量、移交、退出和解散 |
| F-11 至 F-13 | 选题管理 | 组长提交、标准化查重、教师审核和通知 |
| F-14 至 F-19 | 作业与提交 | Tiptap 富文本说明、HTML 白名单清洗、先草稿后附件再发布、私有文件、正式提交、不可变版本、截止前按附件清单更新提交和提交看板 |
| F-20 至 F-21 | 下载与预览 | 默认单文件上限 500 MiB、分块读取上传、扩展名/MIME/空文件校验、鉴权异步 ZIP；PDF.js/图片/Markdown 预览及定位批注；Office 与压缩包仅下载；私有 OSS 存储 |
| F-22 | 成绩计算 | 当前个人作业的组内 A-E 互评取平均等级，教师评级优先；历史百分制活动及小组系数仍可读取 |
| F-23 至 F-25 | 作品互评 | 当前组员可评价本组其他成员的最新个人正式提交；禁止自评、跨组及评价未提交对象；新版本重新评价。历史一对一冻结分配接口保留 |
| F-26 | 成绩与历史 | 当前个人作业按教师评级、互评等级、逾期未交系统 E 的优先级展示结果；历史百分制成绩仍保留发布、系数与版本记录 |
| F-27 | 站内通知 | 业务触发、未读统计和全部已读 |
| F-28 | 统计导出 | 成员、小组和互评导出；成绩按单次作业导出 XLSX/CSV，并包含全部参与者与状态 |
| F-29 | 审计日志 | 关键写操作持久化、教师分页查询 |

运行环境不包含示例课程或学生。固定教师是唯一引导账号；后端集成测试使用 Compose 的独立 SQL Server，文件操作使用与开发、生产隔离的测试 OSS 前缀。

本期不安装或调用 LibreOffice，也不在浏览器端解析 Office；DOCX/PPTX/XLSX 始终通过鉴权接口下载原文件。ZIP 档案由后台任务异步生成，CSV/XLSX 表格导出仍同步生成。备份恢复和性能指标按实际部署资源执行运维验收。
