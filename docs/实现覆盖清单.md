# PRD 实现覆盖清单

> 正式版：V2.0  
> 核对日期：2026-09-15

| 编号 | 功能 | 正式实现 |
|---|---|---|
| F-01 至 F-04 | 认证、教学班、名单与首页 | PostgreSQL 会话、建班、多工作表名单识别与预检确认、成员单独增删改查、学号账号和真实摘要 |
| F-05 至 F-10 | 小组管理 | 创建、申请、审批、邀请、容量、移交、退出和解散 |
| F-11 至 F-13 | 选题管理 | 组长提交、标准化查重、教师审核和通知 |
| F-14 至 F-19 | 作业与提交 | Tiptap 富文本说明、HTML 白名单清洗、先草稿后附件再发布、私有文件、正式提交、不可变版本、截止前按附件清单更新提交和提交看板 |
| F-20 至 F-21 | 下载与预览 | 单文件最大 100 MB、分块上传、扩展名/MIME/空文件校验、权限校验批量 ZIP、PDF/图片直览、安全 Markdown 预览；DOCX/PPTX/XLSX 与压缩包仅下载 |
| F-22 | 教师评分 | 个人/小组评分、0 至 100 校验、草稿和发布 |
| F-23 至 F-25 | 一对一作品互评 | 新建个人作业时可配置截止后自动创建；按组或全班循环分配；候选人、提交版本和组别事务冻结；单人组跳过；总分/必填评语、统计和作废 |
| F-26 | 成绩发布 | 发布确认、学生可见范围、通知、已发布成绩修改原因和版本历史 |
| F-27 | 站内通知 | 业务触发、未读统计和全部已读 |
| F-28 | 统计导出 | 成员、小组、成绩和互评 XLSX/CSV 导出 |
| F-29 | 审计日志 | 关键写操作持久化、教师分页查询 |

运行环境不包含示例课程或学生。固定教师是唯一引导账号；自动测试使用独立临时数据库，测试数据仅存在于测试容器生命周期内，不接触开发运行数据。

本期不安装或调用 LibreOffice，也不在浏览器端解析 Office；DOCX/PPTX/XLSX 始终通过鉴权接口下载原文件。批量 ZIP 与表格导出当前同步生成，适合首版课程规模；更大数据量再切换到已有任务表驱动的异步处理。备份恢复和性能指标按实际部署资源执行运维验收。
