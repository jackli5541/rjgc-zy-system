# 毕业设计选题

## 题目

面向软件工程课程的团队化作业与过程性评价系统的设计与实现

## 研究方向

软件工程 / Web 应用开发（教育信息化方向）

## 题目简介

软件工程是一门实践性很强的课程，教学中大量采用小组协作的方式完成作业和课程大作业。传统方式依赖网盘、即时通讯工具和电子表格管理作业，存在作业收发分散、提交版本难以追溯、小组内分工与个人贡献不透明、评价以期末结果为主而缺少过程数据等问题，难以落实过程性考核。

本课题面向软件工程课程的理论与实验教学，设计并实现一个团队化作业与过程性评价系统。系统采用前后端分离的 B/S 架构：后端基于 Python FastAPI 框架，使用 SQLAlchemy 与 Alembic 管理 SQL Server 数据库；前端基于 Vue 3 与 Ant Design Vue；文件采用对象存储保存。系统按业务划分为系统管理（登录、权限、审计、通知）、学员管理（教学班、成员、小组组建与选题）、作业管理（发布、附件、在线 Markdown 文档、版本化提交、批阅批注、同伴互评）、大作业、教学资料、考勤、成绩统计与导出、教学总览等模块。

系统能在教学全过程中留存作业提交、批阅、互评和考勤等过程数据，结合小组贡献系数形成个人成绩，为教师落实过程性评价提供信息化支撑，也提升学生团队协作的规范性。

## 基本要求

### 一、调研与分析

1. 调研高校课程作业管理及过程性评价的现状，分析现有平台（如通用的学习管理系统）在团队化作业方面的不足。
2. 完成需求分析，明确教师、学生两类角色的功能需求与非功能需求，给出用例图和业务流程图。

### 二、系统设计

1. 完成总体架构设计，采用前后端分离与模块化设计，模块之间依赖清晰、不出现循环依赖。
2. 完成数据库概念设计与逻辑设计，给出 E-R 图和主要数据表结构，并通过迁移脚本管理数据库结构的演进。
3. 设计统一风格的 RESTful 接口和结构化的错误响应。

### 三、功能实现

1. 实现教学班、成员、小组及选题管理，支持个人作业与小组作业两种提交方式。
2. 实现作业的发布、附件上传与预览、在线 Markdown 文档编辑，以及多版本提交与追溯。
3. 实现教师批阅与批注、同伴互评任务的分配与评分，以及成绩系数计算、成绩统计与 Excel 导出。
4. 实现大作业、教学资料、考勤、通知与操作审计等辅助功能。
5. 界面适配 PC 端和移动端。

### 四、安全与质量

1. 实现基于会话的身份认证、CSRF 防护、按角色与班级划分的权限控制，以及文件访问控制。
2. 编写自动化接口测试，覆盖权限、参数校验、数据一致性等关键场景，并完成功能测试与性能测试。

### 五、成果要求

1. 提交可以部署运行的系统源代码及部署说明。
2. 完成符合学校规范的毕业论文。字数按学院要求，一般不少于 1.5 万字。
3. 完成外文文献翻译、开题报告等过程材料，并按时参加中期检查和答辩。
